# Reply policy

ARG Data replies to claims, not people.

- No insults, dunking, partisan slogans or speculation about motives.
- State what is true before what is misleading/false.
- Link the primary evidence or ARG Data evidence page.
- If the evidence is incomplete, say so and do not issue a categorical verdict.
- Correct ARG Data publicly if later official revisions materially change a verdict.
- Never optimize replies based on whether the result helps or harms a government or party.
- V0 requires human approval for every political/economic reply.
